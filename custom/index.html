Where these live

Files in your own user folder, not inside the app — so they survive updates, and nothing is uploaded anywhere.

How they run

Each one opens in a sandbox with no access to the rest of the app, so a file from somewhere you don't fully trust still can't read anything else.

What to put in them

Same rule as the built-in collection: invent the brand. Copying a real company's name and logo into a mock-up is the one thing that turns a design study into a problem.
